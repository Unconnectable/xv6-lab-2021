# Chapter 1 Operating system interfaces

**文件描述符(File Descriptor)** 是操作系统中用于标识打开文件或 I/O 资源(如管道、网络套接字等)的一个整数值

**标准文件描述符**

- 在 Unix/Linux 系统中，有三个预定义的标准文件描述符：
  - `0`：标准输入(stdin)
  - `1`：标准输出(stdout)
  - `2`：标准错误(stderr)

```c
int fd = open("file.txt", O_RDONLY);  // 打开文件，返回文件描述符
if (fd == -1) {
    perror("Error opening file");
} else {
    char buffer[100];
    read(fd, buffer, 100);  // 通过文件描述符读取文件内容
    close(fd);  // 关闭文件描述符
}
```

**PID** 是 **Process ID**(进程 ID)的缩写，是操作系统中用于唯一标识一个正在运行的进程的整数值。每个进程在创建时都会被分配一个独特的 PID，直到进程终止

​	在同一时刻，系统中每个进程的 PID 是唯一的。



重定向子进程的 I/O 是指通过修改子进程的文件描述符，使其指向其他文件或管道，从而改变子进程的输入来源或输出目标。

### 1. **进程管理相关函数**

#### (1)`int fork()`

- **全称**：Fork(分叉)
- **单词意思**：`fork` 意为“分叉”，表示创建一个新的进程。
- **功能**：创建一个与父进程几乎完全相同的子进程。子进程从 `fork` 返回的地方开始执行。
- **返回值**：
  - 父进程返回子进程的 PID。
  - 子进程返回 `0`。
  - 失败返回 `-1`。

#### (2)`int exit(int status)`

- **全称**：Exit(退出)
- **单词意思**：`exit` 意为“退出”，表示终止当前进程。
- **功能**：终止当前进程，并返回状态码 `status` 给父进程。

#### (3)`int wait(int *status)`

- **全称**：Wait(等待)
- **单词意思**：`wait` 意为“等待”，表示等待子进程结束。
- **功能**：等待任意一个子进程结束，并将子进程的退出状态存储在 `status` 中。
- **返回值**：结束的子进程的 PID。

#### (4)`int kill(int pid)`

- **全称**：Kill(杀死)
- **单词意思**：`kill` 意为“杀死”，表示终止指定进程。
- **功能**：向进程 `pid` 发送终止信号，使其退出。
- **返回值**：成功返回 `0`，失败返回 `-1`。

#### (5)`int getpid()`

- **全称**：Get Process ID(获取进程 ID)
- **单词意思**：`getpid` 意为“获取进程 ID”。
- **功能**：返回当前进程的 PID。

#### (6)`int sleep(int n)`

- **全称**：Sleep(睡眠)
- **单词意思**：`sleep` 意为“睡眠”，表示暂停执行。
- **功能**：使当前进程暂停执行 `n` 个时钟周期。

#### (7)`int exec(char *file, char *argv[])`

- **全称**：Execute(执行)
- **单词意思**：`exec` 意为“执行”，表示加载并执行新程序。
- **功能**：用 `file` 指定的程序替换当前进程的内存空间，并传递参数 `argv`。
- **返回值**：成功不返回，失败返回 `-1`。

### 2. **文件操作相关函数**

#### (1)`int open(char *file, int flags)`

- **全称**：Open(打开)
- **单词意思**：`open` 意为“打开”，表示打开文件。
- **功能**：打开文件 `file`，并返回文件描述符。
- **返回值**：成功返回文件描述符，失败返回 `-1`。

#### (2)`int write(int fd, char *buf, int n)`

- **全称**：Write(写入)
- **单词意思**：`write` 意为“写入”，表示向文件写入数据。
- **功能**：向文件描述符 `fd` 写入 `buf` 中的 `n` 字节数据。
- **返回值**：成功返回写入的字节数，失败返回 `-1`。

#### (3)`int read(int fd, char *buf, int n)`

- **全称**：Read(读取)
- **单词意思**：`read` 意为“读取”，表示从文件读取数据。
- **功能**：从文件描述符 `fd` 读取 `n` 字节数据到 `buf`。
- **返回值**：成功返回读取的字节数，失败返回 `-1`。

#### (4)`int close(int fd)`

- **全称**：Close(关闭)
- **单词意思**：`close` 意为“关闭”，表示关闭文件。
- **功能**：关闭文件描述符 `fd`。
- **返回值**：成功返回 `0`，失败返回 `-1`。

#### (5)`int dup(int fd)`

- **全称**：Duplicate(复制)
- **单词意思**：`dup` 意为“复制”，表示复制文件描述符。
- **功能**：复制文件描述符 `fd`，返回一个新的文件描述符。
- **返回值**：成功返回新的文件描述符，失败返回 `-1`。

#### (6)`int pipe(int p[2])`

- **全称**：Pipe(管道)
- **单词意思**：`pipe` 意为“管道”，表示创建管道。
- **功能**：创建一个管道，并将读端和写端的文件描述符存储在 `p[0]` 和 `p[1]` 中。
- **返回值**：成功返回 `0`，失败返回 `-1`。

### 3. **文件系统相关函数**

#### (1)`int chdir(char *dir)`

- **全称**：Change Directory(更改目录)
- **单词意思**：`chdir` 意为“更改目录”，表示切换当前工作目录。
- **功能**：将当前工作目录更改为 `dir`。
- **返回值**：成功返回 `0`，失败返回 `-1`。

#### (2)`int mkdir(char *dir)`

- **全称**：Make Directory(创建目录)
- **单词意思**：`mkdir` 意为“创建目录”，表示创建新目录。
- **功能**：创建目录 `dir`。
- **返回值**：成功返回 `0`，失败返回 `-1`。

#### (3)`int mknod(char *file, int major, int minor)`

- **全称**：Make Node(创建节点)
- **单词意思**：`mknod` 意为“创建节点”，表示创建设备文件。
- **功能**：创建特殊文件(如设备文件)，`major` 和 `minor` 指定设备号。
- **返回值**：成功返回 `0`，失败返回 `-1`。

#### (4)`int fstat(int fd, struct stat *st)`

- **全称**：File Status(文件状态)
- **单词意思**：`fstat` 意为“文件状态”，表示获取文件状态。
- **功能**：获取文件描述符 `fd` 对应的文件状态，并存储在 `st` 中。
- **返回值**：成功返回 `0`，失败返回 `-1`。

#### (5)`int stat(char *file, struct stat *st)`

- **全称**：Status(状态)
- **单词意思**：`stat` 意为“状态”，表示获取文件状态。
- **功能**：获取文件 `file` 的状态，并存储在 `st` 中。
- **返回值**：成功返回 `0`，失败返回 `-1`。

#### (6)`int link(char *file1, char *file2)`

- **全称**：Link(链接)
- **单词意思**：`link` 意为“链接”，表示创建硬链接。
- **功能**：为 `file1` 创建硬链接 `file2`。
- **返回值**：成功返回 `0`，失败返回 `-1`。

#### (7)`int unlink(char *file)`

- **全称**：Unlink(取消链接)
- **单词意思**：`unlink` 意为“取消链接”，表示删除文件。
- **功能**：删除文件 `file`。
- **返回值**：成功返回 `0`，失败返回 `-1`。
